# Instant Expert Advisor — Neon Decision Lab

**Original concept, design and development by Cornelius Aurelius** — https://corneliusaurelius.com/

Public application: https://cornelius-aurelius.github.io/instant-expert-neon/
Original reference preserved: https://zenodo.org/records/17362534

A GitHub Pages-ready, no-build structured decision planning application. The original version returned randomly selected generic bullet points; this edition uses question/context/domain-specific deterministic planning prompts. It does not impersonate a live AI model or professional advisor.

## Functionality
- Six domains; goal/context/constraint/success framing; priorities/horizon/confidence.
- Practical step plan, risks, questions and optional two-path comparison, with no fabricated winner.
- Three examples; editable report, copy, download to text and print/PDF.
- Optional browser-local save/load/delete with clear unencrypted/shared-device caveat, no user data submission.
- Responsive mobile/desktop design, accessible controls, reduced motion, SEO + linked schema.org creator metadata.
- Maintains original Zenodo reference; no historical timestamps were changed.

## Tests
Run `node --test tests/*.test.cjs`; then open `index.html` in a browser or on GitHub Pages. The tool needs no backend or API key.

## Note
For live AI-powered expert consultation, a separate secure backend and a clearly scoped model integration would be necessary. This application makes no such claim.
